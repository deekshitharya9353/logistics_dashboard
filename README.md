🚚 Logistics Dashboard — Power BI
📊 Overview

This project is an interactive Logistics Dashboard developed using Microsoft Power BI to analyze and monitor key logistics operations.

The dashboard provides insights into orders, delivery performance, drivers, hubs, and vehicles, helping users understand operational efficiency and identify areas that may require attention.

🎯 Project Objectives
Monitor overall logistics performance
Analyze order and delivery trends
Track on-time delivery performance
Understand customer satisfaction
Analyze driver performance and experience
Monitor vehicle status and breakdowns
Analyze hub capacity and operations
Create an interactive and easy-to-use reporting dashboard

📌 Dashboard Sections
1. 📦 Orders Overview

Provides insights into order and delivery performance, including:

Total Orders
On-Time Delivery Rate
Customer Satisfaction (CST %)
Average Delivery Time
Vehicle Type
Number of Vehicles
Monthly and yearly analysis

2. 👨‍✈️ Driver Overview

Analyzes driver-related information such as:

Number of Drivers
Driver Names
Driver Experience
Performance Rating
Delayed Rate
Hiring information
Driver-level performance analysis

3. 🏢 Hubs Overview

Provides information about logistics hubs, including:

Number of Hubs
Hub Names
Hub Capacity
Hub-level analysis

4. 🚛 Vehicle Overview

Tracks vehicle-related operational information:

Vehicle Model
Vehicle Code
Vehicle Status
Vehicle Age
Vehicle Breakdowns
Vehicle Type

📈 Key KPIs

The dashboard focuses on important logistics KPIs such as:

KPI	Purpose
Total Orders	Measures overall order volume
On-Time Delivery Rate	Tracks delivery efficiency
Customer Satisfaction	Measures customer experience
Average Delivery Time	Monitors delivery speed
Driver Performance	Evaluates driver effectiveness
Delayed Rate	Tracks delivery delays
Vehicle Breakdowns	Monitors vehicle reliability
Hub Capacity	Helps understand hub operations
